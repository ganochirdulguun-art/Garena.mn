Цонхоо хаахгүйгээр, тоглолтынхоо дундуур skill-ийн үсгээ тааруул.

Ердийн WarKey тоглоомоо хаагаад тохируулдаг. Garena.mn WarKey бол тоглоомоосоо гаралгүйгээр, яг тоглож байхдаа skill болон item-ийн hotkey-гээ шинэчилдэг шинэ төрлийн хэрэгсэл.

Hero-гоо буруу үсэгтэй эхлүүлчихсэн үү? Ctrl + F6 дарахад тоглолтынхоо яг дээр overlay гарч ирнэ. Skill болон item-ийн hotkey-гээ шууд өөрчлөөд, дахин Ctrl + F6 дарж хаагаад тоглоомоо үргэлжлүүлнэ — alt-tab, restart юу ч хэрэггүй.

⬇️WarKey суулгах

WarKey татах

Дээрх "WarKey татах" товчоор GarenaWarKey.exe файлыг татна. Суулгац шаардлагагүй — шууд нээгддэг.

Windows анхааруулбал

SmartScreen гарвал → More info → Run anyway. (Платформтой ижил хэвийн зүйл.)

Discord-оороо нэвтрэх

WarKey нээгдэхэд Discord-оороо нэвтэрнэ — эрх шалгаад бэлэн болно.

Warcraft III нээх

WC3-аа нээхэд WarKey ард ажиллаж эхэлнэ. Дээд талд Вито Корлеон шиг нэр чинь гарч ирвэл холбогдсон гэсэн үг.

⌨️WarKey хэрэглэх

Үсгээ урьдчилан тааруул

Warkey таб дээр Skill, Inventory (1–6) hotkey-гээ өөрийн гарын байрлалд тохируулна. QuickChat таб-д давтагддаг чатаа тавина.

Hero-гоо сонго

Тоглолт эхлүүлж hero-гоо сонгоход тухайн баатрын skill-үүд автоматаар Skills самбарт гарч ирнэ.

Тоглож байхдаа Ctrl + F6

Тоглоомынхоо яг дундуур Ctrl + F6 дарж overlay нээнэ. Тоглоомоо хаах, alt-tab хийх шаардлагагүй.

Үсгээ солиод үргэлжлүүл

Overlay дээр skill/item-ийн үсгээ шинэчилнэ. Дахин Ctrl + F6 дарж хаагаад тоглоомоо шууд үргэлжлүүлнэ.

⬇️Суулгах заавар

Installer татах

Дээрх "Платформ татах" товч эсвэл доорх Татах хэсгээс Garena.mn Setup файлыг татна.

Windows анхааруулбал

"Windows protected your PC" (SmartScreen) гарвал → More info → Run anyway дарна. Энэ нь шинэ апп бүрт гардаг хэвийн зүйл, вирус биш.

Суулгах

Next → Install дарж дуустал хүлээнэ. Desktop дээр Garena.mn icon үүснэ.

Discord-оороо нэвтрэх

Апп нээгдэхэд Discord-оороо нэвтэрнэ. GarenaSystem серверийн гишүүн бол Tier чинь шууд орж ирнэ.

Санамж: Хэрэв SmartScreen "Run anyway" сонголт харагдахгүй бол файл дээр баруун товч → Properties → Unblock тэмдэглээд OK дарна.
