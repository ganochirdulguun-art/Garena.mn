⬇️Суулгах заавар

Installer татах

Дээрх "Платформ татах" товч эсвэл доорх Татах хэсгээс Garena.mn Setup файлыг татна.

Windows анхааруулбал

"Windows protected your PC" (SmartScreen) гарвал → More info → Run anyway дарна. Энэ нь шинэ апп бүрт гардаг хэвийн зүйл, вирус биш.

Суулгах

Next → Install дарж дуустал хүлээнэ. Desktop дээр Garena.mn icon үүснэ.

Discord-оороо нэвтрэх

Апп нээгдэхэд Discord-оороо нэвтэрнэ. GarenaSystem серверийн гишүүн бол Tier чинь шууд орж ирнэ.

Санамж: Хэрэв SmartScreen "Run anyway" сонголт харагдахгүй бол файл дээр баруун товч → Properties → Unblock тэмдэглээд OK дарна.
