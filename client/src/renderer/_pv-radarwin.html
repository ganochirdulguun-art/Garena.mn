        ⌨ Garena.mn WarKey

        Цонхоо хаахгүйгээр, яг тоглож байхдаа skill, item, QuickChat товчоо тааруулдаг шинэ төрлийн WarKey. Ердийн WarKey тоглоомоо хаагаад тохируулдаг — Garena.mn WarKey тоглолтын дундуур Ctrl+F6 дараад overlay дээрээс шууд солино.

        Суулгац шаардлагагүй, шууд нээгддэг · Windows 10/11 · Discord-оор нэвтэрнэ · шинэчлэлт автоматаар

        Давуу тал

        ⚡Ctrl+F6 — тоглоом дотор

        Hero-гоо буруу үсэгтэй эхлүүлчихсэн үү? Ctrl+F6 дарахад overlay гарч, skill/item-ийн товчоо шууд солиод үргэлжлүүлнэ. Alt-tab, restart хэрэггүй.

        🎯Skill + Inventory нэг дор

        Тоглолт эхэлж hero сонгомогц skill-үүд автоматаар танигдана; inventory 2×3 (Num7…Num2) товчнуудаа өөрийн үсэг, Mouse4/5, дугуй руу шилжүүлнэ.

        💬QuickChat

        Давтагддаг мессежээ (gg, miss top, b…) нэг товчинд тавь. Нэг товчинд хэд хэдэн мессеж дарааллаар илгээнэ.

        🧠Чат ухаалаг

        Чат нээлттэй үед remap түр зогсдог тул мессеж бичих үед skill санамсаргүй цохихгүй.

        🔄Авто-шинэчлэлт

        Шинэ хувилбар гармагц өөрөө татаж суулгана. Нэг л удаа суулгаад л болно.

        🔐Garena.mn-тэй хамт

        GarenaSystem тэмцээний түүхтэй бол хаана ч (GameRanger, PC төв); бусад нь Garena.mn платформ нээлттэй үед ашиглана.

        Суулгах заавар

        1. Дээрх «WarKey татах» товчоор GarenaWarKey.exe-г татна (суулгац биш, шууд нээгддэг).
        2. Windows SmartScreen гарвал More info → Run anyway; хөтөч «Keep» асуувал Keep.
        3. Файл дээр баруун товч → Run as administrator (WC3 админ эрхээр ажилладаг бол skill унших, солиход заавал).
        4. Хөтөч нээгдэж Discord-оор нэвтэрнэ — платформтой ижил акаунт. Дараа нь санана.
        5. Цонхыг хаахад tray-д үргэлжлэн ажиллана.

        Хэрэглэх заавар

        1. Inventory 2×3: слот дээр дараад өөрийн товчоо дарна (Backspace = арилгах).
        2. QuickChat: товч + мессеж нэмнэ (F2 → «gg wp»).
        3. Тоглолт эхэлж hero сонгосны дараа Skills жагсаалт гарна — skill бүрд үсэг өгнө.
        4. Тоглоом дотор Ctrl+F6: overlay-аас slot-ын дугаар дараад шинэ үсгээ дарна. Дахин Ctrl+F6 / Esc = хаах.
        5. Skill-ийн үсэг тоглолт бүрд шинээр тааруулагдана (өмнөх тоглолтоос дамжихгүй).

        Асуудал гарвал: WarKey-г Run as administrator-оор нээх; нэг зэрэг хоёр WarKey ажиллуулахгүй; шинэчлэлтийг апп өөрөө татна.

        📡 Радар

        Явж буй тоглолтыг гаднаас нь LIVE (саатлаар) болон дууссан тоглолтыг replay-ээр — hero-гийн хөдөлгөөн, үхэл, kill газрын зураг дээр. Байрлал = тушаалуудаас симуляцилсан ойролцоо утга; kill/death яг цагаар. LIVE 120 с саатлаар — оролцогч өөрийн тоглолтыг харахгүй.

        Ачааллаж байна…
        Зүүн жагсаалтаас LIVE эсвэл replay тоглолт сонго.
        🥇 GOLD ОНЦЛОГ

        Тоглолтыг гаднаас нь LIVE радараар үз

        Радар нь явж буй тоглолт бүрийн hero-гийн хөдөлгөөн, үхэл, kill-ийг газрын зураг дээр 120 секундын саатлаар (тэмцээний шударга байдлыг хамгаалахын тулд) LIVE симуляцилж үзүүлнэ. Дууссан тоглолтыг replay-ээр эргүүлж үзэх боломжтой. Баруун талд бодит тоглолтын демо явж байна.

        Таны одоогийн гишүүнчлэл: Bronze. Радар зөвхөн GOLD гишүүдэд нээлттэй.

        1. Профайл таб → Гишүүнчлэл хэсэгт очно.
        2. GOLD сонгоод QPay (эсвэл Diamond ◆) -аар төлнө — 1 сар.
        3. Төлбөр батлагдмагц Радар шууд нээгдэнэ (LIVE 120 с саатал + бүх replay). Дагалдах: нэрийн эффект, аватарын хүрээ, GOLD өрөөний дэвсгэр.
        Тоглолтод оролцож буй тоглогч өөрийн тоглолтын радарыг харах боломжгүй — GOLD гишүүн ч мөн адил.
        Демо ачааллаж байна…
        ҮНЭГҮЙ · АВТОМАТ ДҮН · DIAMOND ОЛБОРЛОЛТ

        🏆 Ranked — тоглонгоо Diamond олборло

        Ranked өрөөнд тоглосон тоглолт бүрийн дүн (K/D/A, creep, denie, neutral, gold, hero, item) DATACOM relay серверээс автоматаар бүртгэгдэж, хүчинтэй хожил бүрд +2 💎 олгоно. Бот хост ч, replay ч хэрэггүй — бидний ялсан LAN холболт дээрээ шууд.

        Энгийн өрөө XP л өгнө · Ranked зөвхөн платформоор нэгдсэн тоглогчдод тоологдоно

        Яагаад Ranked?

        💎Хожил бүрд 2 Diamond

        Хүчинтэй ranked хожил бүр +2 💎, 10 ranked тоглолтын блокт ≥5 хожвол нэмж +30 💎. Diamond-оор Silver (800) / Gold (1500) гишүүнчлэл авна, найздаа бэлэглэнэ.

        📊Бодит статистик

        Тоглогч бүрийн K/D/A, creep/denie, neutral, gold, hero, item тоглоом дуусмагц серверт хадгалагдаж профайлд харагдана — хэн ч гараар оруулахгүй, худлаа бичих боломжгүй.

        🛡️Шударга орчин

        MapHack илрүүлэлт (3 сануулга → бан), ижил бүрэлдэхүүн өдөрт 3 хүртэл, 10 минутын өмнө гарсан хүн хожил авахгүй — фермлэлт, хуйвалдаан ашиггүй.

        📈Карьер, түүх

        Хожил/хожигдол, win rate, тоглолтын түүх, XP ба Level профайлд хуримтлагдана. Тэмцээнд орохын өмнө бодит чадвараа харуулна.

        🚀Хамгийн хурдан LAN

        DATACOM relay ~6мс ping; тоглогч бүрийн ping өрөөнд харагдана — хэн гацааж байгааг шууд мэднэ.

        🆓Үнэгүй

        Ranked-д ямар ч төлбөр байхгүй. Өрөө үүсгэхдээ 🏆 сонгоод л тоглоно.

        Хэрхэн тоглох вэ

        1. Өрөө үүсгэх → «🏆 Ranked өрөө» checkbox-ийг сонго (жагсаалтад 🏆 тэмдэгтэй).
        2. 6+ тоглогч (3v3-аас дээш) — хоёр багт тус бүр ≥3 тоглогч платформоор «Нэгдэх» дарж орно. 1v1, 2v2 💎 өгөхгүй.
        3. Хост «LAN тоглоом нээх» → WC3 → LAN → Create Game; бусад нь WC3-ийн LAN жагсаалтаас нэгдэнэ.
        4. ≥12 минут тоглоод -ff эсвэл throne-оор ялагчтай дуусга.
        5. Тоглоом дуусмагц дүн + 💎 автоматаар. Профайл → Diamond · XP хэсэгт харна.

        Зөвлөмж

        • Хостоор ногоон ping-тэй хүн нээвэл хамгийн тогтвортой (өрөөний жагсаалтад тоглогч бүрийн ping харагдана).
        • Платформоо хамгийн сүүлийн хувилбарт байлга (авто-шинэчлэлт) — гацалтын засварууд орсон.
        • Тоглоомоос эрт гарахгүй: 10 минутын өмнө гарвал хожил тоологдохгүй, багаа ч хохироно.
        • WC3-ийн LAN нэр тань нэгдэхэд автоматаар бүртгэгдэнэ — нэрээ тоглолтын дундуур бүү соль.
        • MapHack бүү хэрэглэ: 3 удаагийн сануулгын дараа платформоос бан болно.

        Diamond бол платформын доторх оноо: Silver/Gold гишүүнчлэл, бэлэглэлтэд зарцуулна; платформ мөнгөөр буцаан авахгүй, бэлэн мөнгөөр наймаалцахыг дэмжихгүй.
